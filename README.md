# SENA Learning App

Aplicación web para la red de instructores del SENA. Permite registrar instructores, subir guías y consultar el contenido de aprendizaje.

## Stack

- Python + Flask
- MongoDB Atlas (via mongoengine)
- flask-login, flask-mail

## Setup local

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
